# Karxora

A minimalistic, high-performance billing and inventory dashboard built with React, Vite, and Supabase.

## Features

- Real-time billing and sales tracking
- Inventory management
- Team user management for admin and employee accounts
- Supabase backend for secure database storage

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up your `.env` variables for Supabase (`VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`).
3. Run the app:
   ```bash
   npm run dev
   ```
